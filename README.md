# TOYLAND — інтернет-магазин іграшок

Проєкт адаптовано з autoshop-project. Next.js 15, React 19, TypeScript, Supabase, CSS, Lucide/MUI (пакети залишені).

## Запуск
1. Створіть **новий** Supabase-проєкт (не використовуйте стару автомобільну БД).
2. У SQL Editor виконайте `supabase/schema.sql` повністю.
3. Створіть `.env.local` з `.env.example`, підставте URL і **publishable/anon** ключ нового проєкту. **Не використовуйте secret/service_role ключ у браузері**.
4. `npm install`, `npm run dev`, відкрийте http://localhost:3000.
5. На `/login` зареєструйте власний акаунт. Якщо увімкнено підтвердження email — підтвердьте його.
6. У Supabase Authentication → Users скопіюйте UUID свого акаунта і в SQL Editor виконайте:
   `update public.profiles set role='admin' where id='ВАШ_UUID';`
7. Перезайдіть в акаунт, відкрийте `/admin` та додайте іграшки.

## Сторінки
`/` — головна, `/catalog` — каталог з пошуком і сортуванням, `/cart` — кошик, `/checkout` — оформлення, `/orders` — власні замовлення, `/login` — реєстрація/вхід, `/admin` — управління товарами й замовленнями.

## Безпека
RLS дозволяє змінювати товари й фото лише ролі `admin`. Покупці не можуть призначати собі роль. RPC `place_order` обчислює ціни на сервері, перевіряє склад і атомарно зменшує залишки. Оплата під час отримання; інтеграції платіжної системи немає. Кошик зберігається в localStorage. Замовлення потребує авторизації.

Примітка: зображення товарів зберігаються в публічному Storage bucket; не завантажуйте туди приватні файли. Для реального магазину додатково потрібні правила доставки/повернення, захист від спаму та юридичні сторінки.
